# Datasets

`golden/` holds the frozen reference sessions. `expected/` holds the engine's
outputs on them. Together they are the numerical contract: the tests compare
the engine against `expected/` on every run, and a future native core must
reproduce the same numbers.

Golden files are never edited. `tools/build_golden.py` records how they were
made; `tools/freeze_expected.py` regenerates `expected/` and is run only when a
calculation is changed on purpose.

| File | What it is | Exercises |
|---|---|---|
| `synthetic_gt3_5lap.csv.gz` | Synthetic GT3 session, 5 laps at 100 Hz, 32 channels, from the point-mass lap simulation in `veltrix_engine.synth` (seed 42). Front-left lock-up on lap 3. | Every derived channel, tyre analysis, load transfer from damper travel, unit guessing (psi with no units row) |
| `logger_layout_3lap_20hz.csv` | Laps 1–3 of the same session laid out like a logger-software CSV export: metadata block, units row, 20 Hz, speed in m/s, accelerations in m/s², no lap channel. | Header parsing, units row, laps from beacon markers, low sample rate |
| `monza_ac_gt3.csv.gz` | McLaren MP4-12C GT3 at Monza (1966 full course, 10,019 m) recorded in the Assetto Corsa simulator. Laps 0–4, one row per metre of track, with position. | Lap-distance resets, uneven time steps, repeated timestamps, track map from position, missing lateral g |

In `monza_ac_gt3.csv.gz` the steering channel is positive in right-hand corners, the opposite
of the schema, and its unit is not degrees. The engine warns about both. The file is kept as
it is so those warnings stay covered.

## What these are not

None of these is data from a real car. The synthetic session has known answers
built in (load transfer split 53% front, understeer that builds each lap, 0.4%
grip loss per lap). The Monza session is simulator output. A real logger export
still needs to be added before the importer can be called validated.

## Licence and source

`monza_ac_gt3.csv.gz` is derived from "Assetto Corsa GT3 Telemetry – Monza Full
Course" by Nasim (nasimrajlaskar) on Kaggle, published under the MIT licence:
https://www.kaggle.com/datasets/nasimrajlaskar/assetto-corsa-gt3-telemetry-monza-full-course

Changes from the original file: lap 5 dropped (bad recording), the per-lap timer
stacked into one session clock, speed converted from m/s to km/h, pedals from
0–1 to %, world X/Y kept as position, other columns dropped.

The synthetic files are generated by this repository.
